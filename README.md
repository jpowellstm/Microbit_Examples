# Microbit_Examples

Examples of code for the BBC microbit written in micropython. 

## Bit::bot examples

bit_bot_basic.py - basic functionality to drive the robot forward, turn and stop.  
bit_bot_ultra.py - includes functionality to use the ultrsound sensor to detect distances.  
bit_bot_neo.py - includes functionality for the neopixels.  
bit_bot_follow.py - includes functionality for the bit::bot to follow a black line on white paper.  
bit_bot_maze.py - basic functionality for navigating throught a maze.  

## Communication examples

Using the inbuilt radio to communicate between microbits.

comm_basic.py - basic set up for messages
comm_channel.py - including power and channel settings
